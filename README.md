# Tertúlia Criminal Curitiba

Landing page do evento Tertúlia Criminal, 20 e 21 de novembro de 2026, no Auditório do Sindimetal/PR (Rua Angelo Greca, 70, Atuba, Curitiba/PR).

Site estático: um `index.html` e a pasta `assets/`. Sem build.

## Links do site

Preencha o bloco `CONFIG` no fim do `index.html`:

- `ingresso`: link da página de compra
- `whatsapp`: número só com dígitos (ex.: 5541999999999)
- `instagram` e `facebook`
